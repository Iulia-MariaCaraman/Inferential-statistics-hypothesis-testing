# Inferential-statistics-hypothesis-testing Inferential Statistics and Hypothesis Testing in Excel

Practical laboratory examination project prepared for Inferential Statistics at the Faculty of Cybernetics, Statistics and Economic Informatics, ASE Bucharest.

## Overview
This repository contains applied statistical test solutions and demographic data evaluations using Microsoft Excel and Data Analysis ToolPak. 

The tasks evaluate differences between sample means, test variance equality across subpopulations, and perform descriptive summary profiling on macroeconomic indicators.

## Applied Statistical Techniques
* Two-Sample z-Test for Means: Tested hypothesis evaluating perceived exam difficulty between grandparent and student generational cohorts in the Bucharest-Ilfov region.
* Two-Sample F-Test for Variances: Evaluated differences in perceived educational support across gender demographics to test variance homogeneity.
* Demographic Group Analysis: Computed weighted mean age, sample variance, standard deviation, and maximum margin of error on grouped population census data.
* Macroeconomic Correlation Profiling: Summarized central tendency, dispersion, skewness, and kurtosis metrics for European Union trade flows and GDP datasets.

## Repository Contents
* Inferential_Statistics_Hypothesis_Testing.xlsx: Complete examination workbook containing hypothesis testing sheets, ANOVA and F-Test output summaries, and source datasets.
